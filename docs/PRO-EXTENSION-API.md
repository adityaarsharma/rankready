# RankReady — Pro Extension API

> Stable contract between RankReady Free (WP.org) and any Pro / commercial addon.
> Available from Free **v1.0.1+**.

The Pro addon is a separate WordPress plugin. It declares `Requires Plugins: rankready-ai-llm-seo` in its header, installs alongside Free, and unlocks gated UI + adds new features by attaching to the hooks below. **It contains zero duplicates of Free code.**

---

## Filter — `rnrd_is_pro`

The single gate that controls every Pro-locked feature in Free.

```php
add_filter( 'rnrd_is_pro', '__return_true' );
```

When this filter resolves to `true`, every "Coming Soon" badge in Free disappears, every locked card becomes interactive, and every Pro-only JSON-LD field becomes editable.

**That's the only line required to unlock everything.**

Free's default value is `false`. The function is defined once in Free (`rnrd_is_pro()` in `rankready.php`) — the addon must not re-declare it.

### What the filter unlocks

| Surface | Behaviour when filter returns `true` |
|---|---|
| Author Box (E-E-A-T) profile screen | Wikidata, ORCID, sameAs, knowsAbout, credentials, Reviewed By, awards become editable |
| Schema settings | HowTo + ItemList auto-detect toggles become saveable |
| Content AI settings | Auto-Generate Summary on publish + Auto-Generate FAQ on publish toggles unlock |
| Branding | "Hide *Generated by RankReady* credit" toggle activates |
| Insights | AI Mention Tracker preview pane renders |
| Tools | Bulk Run cards become interactive (the addon supplies the runner) |

## Action — `rnrd_loaded`

Fires after every core Free class has booted. **The safest moment for an addon to require its own files and instantiate its own classes**, because every public Free API (`RNRD_Generator`, `RNRD_Faq`, `RNRD_Llms_Txt`, `RNRD_Admin`, etc.) is guaranteed to exist.

```php
add_action( 'rnrd_loaded', function () {
	require_once __DIR__ . '/includes/class-my-pro-feature.php';
	My_Pro_Feature::init();
} );
```

Fires once per request, after all Free `*::init()` calls, before `rest_api_init` runs.

## Public Free APIs the addon can compose with

Stable since 1.0.0 unless noted. Method signatures will not change without a major version bump.

### Generation
- `RNRD_Generator::force_generate( int $post_id, bool $skip_unchanged = false ): bool|WP_Error` — single-post AI Summary regeneration
- `RNRD_Faq::generate_faq( int $post_id, string $keyword = '', int $count = 0 ): array|WP_Error` — single-post FAQ regeneration
- `RNRD_LLM::active_provider_ready(): bool` — is the user's chosen LLM key configured

### Content surfaces
- `RNRD_Llms_Txt::get_brand_about(): string` — the brand "About" string the user filled in
- `RNRD_Markdown::render_post( int $post_id ): string` — Markdown body of a post

### Schema graph
- Filter `rnrd_schema_graph` — merge into the `@graph` Free emits, instead of outputting your own `<script type="application/ld+json">`

### Settings groups (use these constants when registering Pro settings)
- `'rnrd_content_group'` — Content AI tab (Summary + FAQ)
- `'rnrd_authority_group'` — E-E-A-T tab (Author + Schema)
- `'rnrd_llms_group'` — AI Crawlers tab
- `'rnrd_settings_group'` — Settings tab (API keys)

## What the addon must NOT do

- ❌ Re-declare `rnrd_is_pro()` directly (use the filter instead)
- ❌ Re-register any option key Free already registered (double-registration silently overrides Free's sanitiser)
- ❌ Bundle a copy of any Free file (`includes/class-rnrd-*.php`)
- ❌ Add WP-Cron events with the `rnrd_*` hook prefix that conflict with Free's scheduled jobs
- ❌ Define `RNRD_*` constants without an `RNRD_PRO_*` prefix

Use the `RNRD_PRO_*` constant prefix and `RNRD_Pro_*` class prefix exclusively. Use the `rnrd_pro_*` filter prefix for anything addon-specific.

## Reference implementation

The official Pro addon (`rankready-pro` v1.1.0+) is the reference:

```
rankready-pro/
├── rankready-pro.php          (registers the filter + boots on rnrd_loaded)
└── includes/
    └── class-rnrd-pro-bulk.php (Bulk Regenerate runner — composes Free's APIs)
```

Total Pro code is ~13 KB. Free code referenced via class methods only. Zero duplication.

## Versioning

This document is the contract. Anything documented here will not change in a backwards-incompatible way without a **major** version bump of Free (`2.x`). New filters / actions / public methods may be **added** at any minor version (`1.x`).

If you ship a third-party Pro extension and a Free update breaks it, that's on Free — file an issue at posimyth.com/support.
